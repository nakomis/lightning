# Logo candidates

Kept so the bikeshedding can continue over future vodka & cokes.

## Round 1 — finding the mark

| File | Concept | Verdict |
|---|---|---|
| `01-offset-slides.png` | Three offset slides implying a bolt | Handsome, but the bolt never quite arrives — reads as an abstract mark, not a lightning talk |
| `02-projector-beam.png` | Projector casting a bolt onto a screen | Clearest concept, worst icon — wide and letterboxed, illegible below ~64px |
| `03-speech-bubble-bolt-flat.png` | Speech bubble with the bolt as negative space | Chosen first. Right shape, but flat and amber, and superseded once the app went blue |

## Round 2 — same mark, with depth

The silhouette was never the problem, so all three keep it. Brief was
"textured / 3D", and the palette had moved from amber to blue by then.

| File | Concept | Verdict |
|---|---|---|
| `04-bolt-cut-crystal.png` | Faceted cut-glass bolt, prismatic, raised off the surface | The best-looking of the three at poster size, and the worst icon — the facets mush into a grey blob by 40px |
| `05-bolt-clay-CHOSEN.png` | Chunky white bolt extruded from a matte ceramic bubble | **Chosen.** The only one of the three whose bolt is still a bolt at favicon size |
| `06-bolt-brushed-metal.png` | Chrome bolt through anodised navy, machined bevels | Most literally textured, but dark on dark — low contrast, muddy small |

The deciding test was rendering all four at 40px, not at 200px. Two of the
three lose the bolt entirely at tab-icon size, which is where this file
actually spends its life.
